Describes the activity or terminal state reported by a sync provider.

[Flags]
public enum CfSyncProviderStatus : uint

Fields

ClearFlags = 2147483648

Clears previously reported activity flags.

ConnectivityLost = 64

The provider has lost connectivity to its backing service.

Disconnected = 0

The provider is not connected to the sync root.

Error = 3221225474

The provider encountered an error that prevents normal operation.

Idle = 1

The provider is connected but has no active synchronization work.

PopulateContent = 8

The provider is populating file content.

PopulateMetadata = 4

The provider is populating placeholder metadata.

PopulateNamespace = 2

The provider is populating placeholder namespace entries.

SyncFull = 32

The provider is performing full synchronization.

SyncIncremental = 16

The provider is performing incremental synchronization.

Terminated = 3221225473

The provider terminated and can no longer service the sync root.

Remarks

Activity values are flags and may be combined. Terminated and Error are terminal status values defined by the native API.
