Remarks

A store contains synchronization coordination metadata only. Implementations must not place file content, authentication credentials, access tokens, or provider-specific business data in the store.

Implementations may serialize transactions internally. Calls are safe from concurrent threads, but each returned transaction and its repositories are single-consumer objects. Dispose the store only after all transactions have completed or been disposed.
