Controls placeholder-management access while a sync provider is connected.

[Flags]
public enum CloudPlaceholderManagementPolicy

Fields

ConvertUnrestricted = 2

Allows any process to convert items to placeholders in an active sync root.

CreateUnrestricted = 1

Allows any process to create placeholders in an active sync root.

ProviderOnly = 0

Restricts placeholder management to the connected provider.

UpdateUnrestricted = 4

Allows any process to update placeholders in an active sync root.

Remarks

Nonzero values require Cloud Files platform integration number 0x310 or later. Values may be combined.
