Adds optional behavior to a sync root's hydration policy.

[Flags]
public enum CloudHydrationPolicyModifiers

Fields

AllowFullRestartHydration = 8

Allows full synchronous hydration when antivirus software scans content whose provider may restart hydration with a different file size.

AutoDehydrationAllowed = 4

Allows Windows to dehydrate in-sync placeholders automatically.

None = 0

Applies no additional hydration behavior.

StreamingAllowed = 2

Allows Windows to deliver provider data without persisting it locally.

ValidationRequired = 1

Requires provider validation before hydrated data is returned to user I/O.

Remarks

ValidationRequired and StreamingAllowed cannot be combined. AllowFullRestartHydration requires Cloud Files platform integration number 0x500 or later.
