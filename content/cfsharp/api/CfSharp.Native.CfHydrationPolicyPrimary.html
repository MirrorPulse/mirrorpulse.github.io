Specifies how the platform hydrates placeholder file content.

public enum CfHydrationPolicyPrimary : ushort

Fields

AlwaysFull = 3

Requires every placeholder to remain fully hydrated.

Full = 2

Hydrates the entire file before completing user I/O.

Partial = 0

Hydrates only ranges required by user I/O.

Progressive = 1

Satisfies requested ranges promptly and continues hydrating remaining content in the background while a user handle remains open.

Remarks

This type uses a 16-bit underlying representation because cfapi.h stores the primary value in CF_HYDRATION_POLICY_PRIMARY_USHORT within the policy structure.
