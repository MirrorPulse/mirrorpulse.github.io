Remarks

An array passed to CfConnectSyncRoot(char*, CfCallbackRegistration*, void*, CfConnectFlags, out CfConnectionKey) must end with an entry whose Type is None and whose Callback is null. The array and every callback entry point must remain valid until CfDisconnectSyncRoot(CfConnectionKey) returns.

Unmanaged stdcall entry point. The callback must not allow exceptions to cross the native boundary and must treat both arguments as borrowed memory valid only for that invocation.
