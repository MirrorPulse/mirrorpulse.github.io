Remarks

This object owns no native handle and does not automatically unregister on disposal or finalization. Registration is persistent across process exits. Call Unregister() only for explicit account removal or product uninstall.

Instances are immutable and safe for concurrent use, but Windows may change the underlying registration between calls. Concurrent register, update, and unregister operations for the same path must be coordinated by the application.

Provider-defined identity returned with future callbacks. The value is copied by Windows and cannot exceed MaxFileIdentityLength bytes.

Returns

Remarks

The placeholder is marked in sync and initially contains no local data. Reading it requires an active CloudProviderSession capable of supplying its identity's content. This method is thread-safe for distinct paths; callers must coordinate competing operations targeting the same path.

Register(string, SyncRootRegistrationOptions)

Registers an existing directory as a persistent Cloud Files sync root.

public static CloudSyncRoot Register(string path, SyncRootRegistrationOptions options)

Parameters

path string

Path of the directory to register.

options SyncRootRegistrationOptions

Immutable provider identity and policy configuration.

Returns

CloudSyncRoot

A path-bound object for querying and explicitly unregistering the root.

Remarks

Registration survives process termination. Registering the same path and equivalent values is idempotent on Windows. To replace existing identities or policies, set UpdateExisting. This method does not introduce compensating unregistration after Windows reports success because the registration may have existed before the call.

Exceptions

ArgumentException

The path is empty or cannot be normalized.

ArgumentNullException

options is null.

DirectoryNotFoundException

The directory does not exist.

PlatformNotSupportedException

Windows predates version 1709 or does not expose the required Cloud Files entry points.

CloudFilesException

Windows rejects registration. The original HRESULT, operation, and path are retained.

Unregister()

Permanently unregisters this sync root.

public void Unregister()

Remarks

This is destructive lifecycle behavior, not session shutdown. Windows traverses the tree, reverts fully available placeholders, and may permanently remove incomplete placeholders. A successful call does not delete the root directory itself.

The object remains usable as a path value, but subsequent queries will fail.

Exceptions

PlatformNotSupportedException

The Cloud Files API is unavailable.

CloudFilesException

Windows rejects unregistration, including when a provider remains connected or the path is no longer registered.
