Remarks

This fixed-size structure is the blittable managed representation of CF_SYNC_ROOT_PROVIDER_INFO. The UTF-16 buffers are null-terminated when the corresponding text occupies fewer than MaxProviderNameLength or MaxProviderVersionLength characters.

The value owns no native resources and remains valid after the query returns.
