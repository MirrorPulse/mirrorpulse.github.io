Supplies remote file content when Windows requests placeholder hydration.

public interface ICloudFileContentProvider

Remarks

Implementations may be called concurrently and must therefore synchronize mutable state. The returned stream must be readable and represent the complete logical file. If seekable, CfSharp positions it at the requested offset; a non-seekable stream is accepted only for a request beginning at offset zero.

The stream is disposed by CfSharp after the request completes. Observe the cancellation token promptly; it is signaled when Windows cancels the request or the provider session shuts down.
