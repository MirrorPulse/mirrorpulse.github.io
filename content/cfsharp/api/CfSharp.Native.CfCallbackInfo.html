Remarks

This is the blittable representation of CF_CALLBACK_INFO. All pointers and identity buffers are borrowed from Windows and remain valid only until the callback returns. Copy any required data before returning and never retain a pointer into this structure.

The same connection may invoke callbacks concurrently. The provider is responsible for synchronizing access to state referenced by CallbackContext.
