Remarks

Read only the field selected by the CfCallbackType used to register the current callback. The structure and every pointer reachable from it are borrowed callback memory and are valid only until the callback returns.

The explicit size and offsets are part of the Windows ABI. ParamSize reports the versioned size supplied by Windows and should be checked before reading fields added by later platform versions.
