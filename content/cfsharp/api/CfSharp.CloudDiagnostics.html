Remarks

CfSharp does not configure exporters, loggers, or listeners. When no listener is attached the implementation keeps the fast path allocation-light. Metric tags must remain low-cardinality and must never contain paths, identities, content, credentials, or device identifiers. Native-failure activities may contain opaque request/connection identifiers and a one-way path fingerprint so a listener can correlate a failure without receiving the caller's path.
