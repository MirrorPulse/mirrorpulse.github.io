Controls how CfRegisterSyncRoot(char*, CfSyncRegistration*, CfSyncPolicies*, CfRegisterFlags) registers a sync root.

[Flags]
public enum CfRegisterFlags : uint

Fields

DisableOnDemandPopulationOnRoot = 2

Disables on-demand population for the sync root directory itself while preserving the configured population policy for its descendants.

MarkInSyncOnRoot = 4

Marks the sync root directory as in sync during registration.

None = 0

Uses the default registration behavior.

Update = 1

Updates the identities and policies of an existing registration.

Remarks

Values may be combined. Unsupported combinations are rejected by the Cloud Files platform with a failing HRESULT.
