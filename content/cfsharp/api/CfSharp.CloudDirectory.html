CreatePlaceholdersAsync(IEnumerable<CloudPlaceholderSpec>, CloudPlaceholderBatchOptions?, CancellationToken)

Creates a validated batch of direct child placeholders.

public ValueTask<CloudPlaceholderBatchResult> CreatePlaceholdersAsync(IEnumerable<CloudPlaceholderSpec> placeholders, CloudPlaceholderBatchOptions? options = null, CancellationToken cancellationToken = default)

Parameters

placeholders IEnumerable<CloudPlaceholderSpec>

File and directory specifications. The sequence is materialized once before mutation; names must be unique under ordinal case-insensitive comparison.

options CloudPlaceholderBatchOptions

Batch behavior, or null for continuing native creation after per-entry failures.

cancellationToken CancellationToken

Token observed before native work and between post-creation steps. Synchronous Cloud Files calls cannot be interrupted after entry.

Returns

ValueTask<CloudPlaceholderBatchResult>

Ordered per-entry results. Native batch and entry failures are retained independently, and a later hydration failure retains completed namespace, durability, and pin steps.

Remarks

Existing placeholders with the exact encoded CfSharp identity are idempotent matches. Unrelated existing items fail unless their specification explicitly requests supersede. All successful namespace entries are persisted in one state-store transaction before any requested hydration. The method owns no handle after completion and is safe for concurrent use on non-overlapping paths while the owning file system remains started.

Exceptions

ArgumentException

The sequence is empty, contains a null entry, or repeats a child name, item identifier, or remote identifier.

CloudPlaceholderPersistenceException

Windows created or matched at least one entry but durable state commit failed.

OperationCanceledException

The operation was canceled at a safe boundary.

DeleteTreeAsync(CloudRecursiveOperationOptions?, CancellationToken)

Deletes the materialized local tree without following symbolic links or junctions.

public ValueTask<CloudRecursiveOperationResult> DeleteTreeAsync(CloudRecursiveOperationOptions? options = null, CancellationToken cancellationToken = default)

Parameters

options CloudRecursiveOperationOptions

Root inclusion and stop-on-first-failure behavior, or null for defaults.

cancellationToken CancellationToken

Token observed between entries and during tombstone persistence. Earlier entries may have completed when cancellation is observed.

Returns

ValueTask<CloudRecursiveOperationResult>

Ordered per-entry results in children-before-parent deletion order.

Remarks

Windows deletion failures are retained in the corresponding entry. A symbolic link or junction is deleted as one entry without visiting or modifying its target.

Exceptions

InvalidOperationException

The sync root was selected while root deletion was enabled.

CloudItemCoordinationException

An entry was deleted but its durable tombstone could not be committed. The exception's PartialResult preserves prior results.

CloudRecursiveOperationCanceledException

Cancellation was observed after one or more entries completed; the exception preserves the partial result.
