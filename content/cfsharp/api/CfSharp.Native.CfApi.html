Remarks

Members of this class preserve native signatures and error values for callers that require direct CFAPI access. They do not translate HRESULT failures into managed exceptions.

Unless a member states otherwise, arguments follow the ownership and lifetime rules documented for the corresponding function in cfapi.h. The entry points are loaded from the copy of CldApi.dll in the Windows system directory.

Callers should therefore treat this as account-removal or uninstall behavior rather than process-session cleanup.

The function retains no buffers and may be called concurrently for separate roots.

CfUpdatePlaceholder(nint, CfFsMetadata*, void*, uint, CfFileRange*, uint, CfUpdateFlags, long*, NativeOverlapped*)

Updates metadata, identity, validity ranges, or state on an existing placeholder.

public static extern int CfUpdatePlaceholder(nint fileHandle, CfFsMetadata* fsMetadata, void* fileIdentity, uint fileIdentityLength, CfFileRange* dehydrateRangeArray, uint dehydrateRangeCount, CfUpdateFlags updateFlags, long* updateUsn, NativeOverlapped* overlapped)

Parameters

fileHandle nint

Open Win32 handle to the placeholder with write-data or write-DAC access. Dehydrating an updated file requires an exclusive handle.

fsMetadata CfFsMetadata*

Optional pointer to replacement file-system metadata. Unless passthrough is requested, zero-valued timestamps and attributes mean unchanged; a zero file size still means zero.

fileIdentity void*

Optional pointer to replacement opaque identity bytes.

fileIdentityLength uint

Length of fileIdentity in bytes; cannot exceed MaxFileIdentityLength.

dehydrateRangeArray CfFileRange*

Optional pointer to page-aligned ranges whose local content becomes invalid.

dehydrateRangeCount uint

Number of entries in dehydrateRangeArray.

updateFlags CfUpdateFlags

Flags selecting the placeholder changes and preconditions.

updateUsn long*

Optional input/output update sequence number. A nonzero input makes the operation conditional; on success Windows writes the final value.

overlapped NativeOverlapped*

Optional caller-owned native overlapped state. For asynchronous completion, all pointed-to buffers and the structure must remain valid until completion is observed.

Returns

int

The native HRESULT without translation, including the HRESULT form of ERROR_IO_PENDING for an asynchronous operation.

Remarks

The operation is atomic with respect to its requested range invalidation: if any supplied range cannot be dehydrated, the update fails rather than leaving torn content. Supplying Dehydrate causes the range array to be ignored.
