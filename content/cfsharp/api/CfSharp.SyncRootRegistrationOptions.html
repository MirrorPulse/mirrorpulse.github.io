Remarks

Use CreateBuilder(string, string) to construct an instance. Identity data is copied during configuration and again during Build(), so later caller or builder mutations cannot alter an existing options object.

Instances own only managed memory, may be retained indefinitely, and are safe for concurrent reads. Registration itself is performed by Register(string, SyncRootRegistrationOptions).
