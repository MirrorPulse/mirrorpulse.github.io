Remarks

This structure ends with the first byte of a variable-length identity. Allocate a native buffer using the byte count returned by CfGetPlaceholderInfo(nint, CfPlaceholderInfoClass, void*, uint, uint*) and read exactly FileIdentityLength bytes beginning at FileIdentity.

The structure owns no memory; the query buffer remains caller-owned.
