Remarks

The feed does not own the supplied state store. When created by CloudFileSystem, the file system stops it before disposing that store. A feed never owns file content and never invokes remote-provider code.

Windows directory notifications are advisory. Buffer overflow, watcher errors, and malformed rename pairs produce RequiresFullRescan. Applications must perform a full reconciliation before acknowledging that condition; periodic reconciliation is intentionally outside CfSharp.
