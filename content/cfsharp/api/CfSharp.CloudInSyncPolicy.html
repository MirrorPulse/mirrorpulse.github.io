Specifies metadata changes that cause Windows to clear a placeholder's in-sync state.

[Flags]
public enum CloudInSyncPolicy : uint

Fields

None = 0

Tracks no additional metadata.

PreserveForSyncEngine = 2147483648

Preserves in-sync state for changes made by the connected provider.

TrackAll = TrackFileAll | TrackDirectoryAll

Tracks every file and directory metadata category recognized by Windows.

TrackDirectoryAll = 11184880

Tracks every directory metadata category recognized by Windows.

TrackDirectoryCreationTime = 16

Tracks directory creation-time changes.

TrackDirectoryHiddenAttribute = 64

Tracks changes to the hidden attribute on directories.

TrackDirectoryLastWriteTime = 512

Tracks directory last-write-time changes.

TrackDirectoryReadOnlyAttribute = 32

Tracks changes to the read-only attribute on directories.

TrackDirectorySystemAttribute = 128

Tracks changes to the system attribute on directories.

TrackFileAll = 5592335

Tracks every file metadata category recognized by Windows.

TrackFileCreationTime = 1

Tracks file creation-time changes.

TrackFileHiddenAttribute = 4

Tracks changes to the hidden attribute on files.

TrackFileLastWriteTime = 256

Tracks file last-write-time changes.

TrackFileReadOnlyAttribute = 2

Tracks changes to the read-only attribute on files.

TrackFileSystemAttribute = 8

Tracks changes to the system attribute on files.

Remarks

Content modification always clears the in-sync state. These values control additional metadata tracking and may be combined independently for files and directories.
