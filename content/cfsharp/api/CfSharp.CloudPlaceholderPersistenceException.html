Remarks

Windows file-system changes and a custom state store cannot share one physical transaction. AppliedResult is immutable and identifies the namespace work completed before the store failure. Callers should retain the failure for diagnostics and reconcile or retry the operation; identity-based retry matching prevents duplicate placeholder creation.
