Remarks

Each InspectAsync(CancellationToken) call creates a new snapshot. A snapshot owns its placeholder-identity bytes and contains no native handles, mutable file-system objects, or live database resources. It is safe for concurrent reads.

Missing local items produce a snapshot with Exists set to false rather than throwing. Durable identity and tombstone properties may still be present. Nullable metadata means that the corresponding fact was not available at inspection time.
