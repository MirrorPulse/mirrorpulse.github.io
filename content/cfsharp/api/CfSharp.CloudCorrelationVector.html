Remarks

The value is telemetry metadata, not a synchronization revision. Only native versions 1 and 2 are accepted. The managed value owns no native memory and can be copied freely. The managed checks enforce the native buffer size and printable ASCII representation; Windows remains the authority for any version-specific correlation-vector grammar.
