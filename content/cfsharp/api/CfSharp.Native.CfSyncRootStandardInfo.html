Remarks

This is the variable-length native CF_SYNC_ROOT_STANDARD_INFO header. The SyncRootIdentity field represents the first byte of trailing identity storage. Callers must allocate the buffer length reported by the query and must not use sizeof(CfSyncRootStandardInfo) as the complete result length when SyncRootIdentityLength is greater than one.

The query buffer is caller-owned. No pointer into that buffer may outlive it, and callers must synchronize access if the buffer is shared across threads.
