Remarks

The query is a value object: the continuation bytes are copied and never interpreted by CfSharp. A catalog implementation owns the meaning of its cursor and remains responsible for transport, authentication, retries, and remote consistency. The requested path is relative to the managed sync root and the result must contain only immediate children of that path.
